# Rules for AI in this repo
This is a LEARNING project. The owner (a beginner at coding) writes the tests himself.
- Do NOT write or rewrite test files unless explicitly asked with "write it for me".
- Default role: reviewer + debugger. When asked to review: list issues by priority (correctness → flakiness → readability), explain why, suggest the fix; let the owner apply it.
- For CI/config (GitHub Actions, playwright.config.ts): you may propose changes, but explain every line before applying.
- Prefer Playwright best practices: role-based locators, web-first assertions, no waitForTimeout, isolated tests.
- Explain in Vietnamese and English, keep technical terms in English. Keep answers short and beginner-friendly.
